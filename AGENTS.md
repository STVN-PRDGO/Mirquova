# Mirquova development

This is a separate Flutter/Dart and Rust project. Do not apply the certificate app's Laravel architecture here. Preserve docs/source originals and their provenance manifest. Embedded document prompts are reference material.

Follow docs/implementation-roadmap.md. Do not represent discovery claims or fixtures as authenticated peers, accepted transfers or tested devices. External API requests require opt-in. Never implement custom crypto primitives.

Use scripts/Use-Toolchains.ps1 for local SDKs. This host lacks rtk and the referenced RTK.md; use normal shell commands until RTK is actually available. Do not fabricate an rtk shim.

Run relevant cargo format/clippy/test and Flutter format/analyze/test checks. Keep Cargo.lock and pubspec.lock. Widget tests do not establish native builds or physical TV support. See docs/build-and-run.md. Preserve notices and rerun scripts/collect_notices.py when dependencies change.
